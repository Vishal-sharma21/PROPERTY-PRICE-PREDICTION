Property Price Prediction Using Machine Learning

Project Overview

This project is a Property Price Prediction Web Application developed using Python, Scikit-learn, and Streamlit. The application predicts property prices based on various property features using machine learning techniques.

The project follows an end-to-end machine learning workflow, including:-

1. Data Cleaning and Preprocessing
2. Exploratory Data Analysis (EDA)
3. Skewness Detection and Handling
4. Feature Scaling
5. Train-Test Split
6. Model Training and Evaluation
7. Hyperparameter Tuning
8. Model Comparison
9. Best Model Selection and Saving
10. Streamlit-Based User Interface


Features:-
1. Predict property prices instantly
2. Interactive Streamlit web application
3. Comprehensive Exploratory Data Analysis (EDA)
4. Distribution  visualizations
5. Skewness detection and treatment
6. Feature scaling and preprocessing
7. Comparison of multiple machine learning models
8. Hyperparameter tuning for performance optimization
9. Automatic loading of the best-performing model
10. Easy-to-use prediction interface


Machine Learning Models Used:-
1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor
4. Gradient Boosting Regressor
5. Support Vector Regressor (SVR)
6. K-Nearest Neighbors Regressor (KNN)

The best-performing model was selected based on evaluation metrics and saved for deployment.


Machine Learning Workflow:-
1. Load and understand the dataset.
2. Perform data cleaning and preprocessing.
3. Conduct Exploratory Data Analysis (EDA).
4. Check and handle skewness.
5. Apply feature scaling.
6. Split data into training and testing sets.
7. Train multiple regression models.
8. Perform hyperparameter tuning.
9. Compare model performance.
10. Save the best-performing model.
11. Deploy the model using Streamlit.


Technologies Used:-
1. Python
2. Pandas
3. NumPy
4. Scikit-learn
5. Matplotlib
6. Seaborn
